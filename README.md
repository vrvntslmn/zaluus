# zaluus

Zaluu Studio website built with React, TypeScript, and Vite.

## Development

```sh
cd zaluustudio
pnpm install
pnpm dev
```

## Build

```sh
cd zaluustudio
pnpm build
```

## Vercel

Import this repository and deploy the `main` branch. Both the repository root
and `zaluustudio` work as the Root Directory: each includes a `vercel.json`
with the install command, build command, and output directory.
